## 1. 产品定义

### 1.1 产品目标

将现有 1280×1024、4:3 的传统工控上位机重新设计为固定 1920×1080、16:9 的 Web HMI，在保留操作员核心工作流的前提下，提升状态可读性、触控效率与视觉层级，并体现前端在 Canvas 图形绘制、坐标换算、数据建模和数据驱动视图方面的能力。整机浏览页第一阶段采用参数化 2.5D Canvas，不引入完整 3D 模型、WebGL 场景或自由漫游。

产品包含两个可通过主导航切换的核心界面：

1. **整机浏览**：以参数化 2.5D Canvas 结构呈现“放卷 → 10 个印刷色组 → 收卷”的整线走料、运行状态和关键生产参数；放卷和收卷同时表达当前活动轴与备用轴，不提供换轴操作。
2. **锁定标记**：显示光电眼实时信号曲线，支持在曲线上通过触控划定、编辑色标检测窗口，并查看首色、前色、本色的偏差。

默认入口：系统启动后进入“整机浏览”页，先展示整线状态和模拟数据刷新；操作员通过主导航进入“锁定标记”页。这样与建议的演示顺序一致。

### 1.2 成功标准

P0 提交门槛：

- 操作员进入系统后 3 秒内可以判断：整机是否运行、当前车速、是否报警、报警来自哪个单元。
- 首次进入整机浏览时不默认选中色组；单击任一色组后可在右侧看到该色组详情，并通过带文字的“查看 PU 检测曲线”入口进入对应锁定标记。
- 进入锁定标记页时默认选中 PU2，自动显示 PU2 的模拟曲线；用户可再切换到 PU3–PU10。
- 锁定标记页默认色组可以显示 1200 点曲线，并按 500ms/帧持续刷新。
- 操作员可以在曲线绘图区完成一次触控或鼠标画框，且检测窗与底层数据坐标正确对应。
- 1920×1080 下无需滚动、无内容截断即可完成两个核心界面的主要 P0 操作。

> 约 20 秒录屏作为可选补充交付项，不计入 P0 代码验收门槛；如提供，建议覆盖整机状态刷新、页面切换、一次完整画框和曲线持续刷新四个片段。

P1 目标标准：

- 操作员点击任一色组，可在一次操作内看到该色组状态与核心参数。
- 进入色组详情后，整线 Canvas 保持可见，右侧默认展示当前 PU 的简化单元原理图；进入对应锁定标记只使用详情中的明确文字按钮。
- 操作员可完成“选择 PU 色组 → 观察曲线 → 触控画框 → 调整或删除 → 查看偏差”的完整闭环。
- P1 功能启用后，窗口编辑、曲线交互和偏差查看不会造成明显卡顿。

### 1.3 用户与场景

| 用户 | 核心任务 | 产品响应 |
| --- | --- | --- |
| 一线操作员 | 看状态、调速度、检查色组、设色标检测窗 | 大字号、大触控区、关键状态常驻、操作即时反馈 |
| 调机/工艺人员 | 查看套色偏差、调整检测窗与凹版辊、比较色组 | 精确数值、参考线、微调工具、选中色组上下文保持 |
| 维护人员 | 快速定位停机或报警单元 | 设备级状态映射、报警聚合、2.5D 定位与详情 |
| 面试评审 | 验证业务理解、设计取舍、工程能力 | 明确的需求映射、数据模型、坐标换算和性能方案 |

## 2. 范围与优先级

### 2.1 P0 - 必须交付

#### 全局

- Vue 3 优先；两个界面通过主导航切换。
- 固定 1920×1080、16:9 工业触摸屏布局，不复刻或拉伸原 4:3 界面。
- 整机浏览页采用 Canvas 渲染参数化 2.5D 工业示意图；锁定标记页采用独立的曲线绘制 Canvas。
- 顶部全局状态栏在两个界面保持一致：订单/材料、车速、整机状态、报警指示、时间。
- 所有业务数据由前端模拟，视图由数据驱动。

#### 整机浏览

- 完整走料示意：放卷 → 10 个印刷色组 → 收卷。
- 显示车速、整机运行/停止状态及独立的报警提示；10 个色组分别显示运行/停止状态、警告或停机级报警。
- 状态数据每 1s 刷新，颜色、图标和有限动画同步变化。
- 报警灯与报警单元在界面中清晰可定位。
- 首次进入时不默认选中色组，右侧显示整线窄摘要，包括整线状态、实际线速度、需处理报警、最新来源和数据状态。
- 单击色组只建立当前 PU 上下文并打开详情，不直接跳转；详情提供明确的“查看 PU 检测曲线”按钮作为跨页面正式入口。

#### 锁定标记

- 每帧曲线包含 1200 个 `{x, y}` 点，500ms 推送一帧并流畅重绘。
- 信号至少包含 2–3 个明显脉冲峰，方便演示检测窗选择。
- 在曲线绘图区通过触控或鼠标拖拽创建矩形检测窗。
- 基础画框采用“按下 → 拖动 → 松开即保存”：松手时立即将矩形保存为当前 PU 的唯一检测窗，不要求先点击“新建”或“确认保存”。
- 曲线数据暂时未到时保留最后一帧并明确显示“信号中断”，不能用零值或空白伪装成正常数据；信号恢复和完整生命周期在 P1 补齐。
- P0 只要求报警灯、报警来源和运行状态清晰可见；报警确认、恢复、复位等完整生命周期在 P1 补齐。
- 正确实现“屏幕坐标 → 数据坐标”的换算；缩放或布局变化后窗口仍与数据对应。

### 2.2 交付口径

- **P0 提交门槛**：考题明确要求的能力，必须完成并通过 P0 验收，构成可提交版本。
- **P1 加分目标**：在 P0 稳定后按剩余时间实现；未完成 P1 不阻塞 P0 版本提交，但已实现的 P1 功能必须通过对应的 P1 验收。
- **P2 工业化扩展**：仅用于表达真实设备接入时需要的示教和运行安全约束；本次考核不要求实现，不进入 P0/P1 验收，也不影响交付。
- 文档中出现的复杂业务规则，除非明确标记为 P0 或 P1，否则均按 P2 设计储备理解；实现时先完成 P0，再按剩余时间选择 P1，不为 P2 预留不可逆的工程复杂度。
- 如提供录屏，应首先展示 P0 闭环；如果 P1 已完成，再在同一段演示中展示 P1 能力。录屏属于补充交付材料，不以录屏有无替代 P0 代码验收。

本次范围冻结：实现工作只以 P0 为最低目标、以 P1 为可选加分；P2 仅用于设计说明和面试交流，不进入本次代码实现或验收清单。20 秒录屏为可选补充交付，不作为 P0/P1 代码完成条件。

本版本对信号、报警和检测窗事务采用“两层交付”口径：P0 提供最小可见、可操作的基础状态和画框闭环；P1 补齐完整生命周期和异常处理。这三类内容均属于本次 P0/P1 范围，不再归入 P2。

### 2.3 P1 - 计划纳入的加分项

#### 整机浏览增强

- 收放卷参数展示增强：总计长、A/B 轴计长、放卷/收卷卷径与报警阈值。
- 快速设定：速度预设、目标速度、自动加速时间、自动减速时间。
- 摆臂位置与引入/引出位置。
- 手动加速、手动减速。
- 详情模式保持整线 Canvas 可见，在右侧默认展示当前 PU 的简化单元原理图，并与关键状态和“查看 PU 检测曲线”入口同屏显示；完整原理图通过“展开”弹层查看。
- 单击 PU 立即选中并打开详情；不使用双击隐藏手势。PU2–PU10 只通过“查看 PU 检测曲线”按钮进入对应锁定标记，PU1 的该入口保持禁用并显示原因。
- 车速、材料运动、辊筒旋转与运行/停止状态联动；报警提示按等级和影响范围叠加显示。

#### 锁定标记增强

- PU2–PU10 色组切换。
- 首色/前色/本色三条参考竖线与稳定颜色映射。
- 曲线底部印刷颜色条带。
- 检测窗口的选中、拖动、八方向调整大小与删除。
- 窗口位置微调，曲线水平平移与缩放。
- 本色/前色/首色的纵向、横向偏差表。
- 曲线冻结/恢复，避免编辑检测窗时受到刷新干扰。

#### 业务闭环增强

- 信号中断与恢复：按超时阈值进入信号异常，保留最后一帧；恢复后经过配置数量的连续有效帧再恢复偏差计算，并显示“信号恢复中/已恢复，待确认”等状态。
- 完整报警生命周期：支持 warning/stop 分级、整机或 PU 影响范围、人工确认、条件恢复、复位/启动等状态流转；确认不等于故障已恢复。
- 检测窗事务流程：支持无窗口时的默认草稿、重新创建时的替换保护、确认保存、取消编辑和恢复上一次有效位置；草稿未确认前不参与偏差和报警。

### 2.4 P2 - 工业化扩展（本次不要求实现）

- 示教/重新锁定首色、前色、本色参考基准，以及停止/低速示教状态。
- 运行态禁止重新锁定、示教状态切换、参考位置候选预览等真实设备安全约束。
- 这些规则保留用于说明业务理解和未来接入真实设备，不作为本次考核的实现或录屏要求。

### 2.5 明确不做

- 录屏约 0:25 出现的第三个“当前偏差”界面不在本次范围内。
- 不逐像素复制原界面，不保留所有冗余数字输入框和历史菜单。
- 不接入真实 PLC、WebSocket 服务、用户权限后端或持久化数据库。
- 不制作完整 3D 数字孪生、复杂光照、自由旋转、自由漫游厂房或设备拆解动画。
- 不引入 Three.js/WebGL 作为整机页第一阶段依赖；如未来需要完整 3D，另行立项评估。
- 2.5D 视觉不作为纯装饰；每一层图形必须承载设备、走料、状态或可操作对象信息。

## 3. 信息架构与全局布局

### 3.1 页面结构

```text
全局应用壳
├── 顶部状态栏（订单 / 幅宽 / 车速 / 联动状态 / 报警 / 时间）
├── 主导航
│   ├── 整机浏览
│   └── 锁定标记
└── 页面工作区
    ├── 整机浏览：2.5D Canvas 整线 + 单元详情 + 参数操作
    └── 锁定标记：色组选择 + 曲线画布 + 调整工具 + 偏差表
```

### 3.2 1920×1080 栅格建议

- 应用整体固定设计基准为 `1920×1080`（16:9），目标工业触摸屏运行时不滚动、不拉伸、不按原 4:3 界面等比缩放。
- 顶部状态栏：`1920×80px`，高优先级信息常驻。
- 下方内容区：`1920×1000px`。
- 左侧主导航：`96×1000px`，仅保留两个核心入口及设置/报警辅助入口。
- 页面工作区：`1824×1000px`（`1920-96`），有效内容按 12 列栅格组织。
- 页面工作区左右内边距各 `24px`，内部可用宽度为 `1776px`；整机浏览采用“全宽总览 / 详情展开”两种布局，不把右侧 `480px` 面板永久挤占在 Canvas 旁。
- 整机总览模式：右侧保留约 `200–240px`、最小不低于 `180px` 的当前对象窄摘要；Canvas 使用摘要以外的剩余宽度和约 `600–680px` 内容高度，保证放卷、10 个色组和收卷完整展开。
- 整机详情模式：整线 Canvas 继续使用右侧面板以外的剩余空间，右侧展开约 `360–420px` 的状态与操作面板，并在面板顶部默认显示当前 PU 的简化单元原理图；完整原理图通过独立弹层展开，不挤压或替换整线 Canvas。
- 锁定标记页继续使用独立的局部曲线 Canvas；本条布局调整只针对整机浏览页。
- 当可用高度低于 `1920×1080` 基准时，已有速度、卷材、张力和事件信息仍需保持可读；Canvas 可进入紧凑布局，但不得裁切连续走料路径、PU 编号或关键状态。
- 标准间距：8px 基线；面板间距 16–24px。
- 触控目标：普通按钮不小于 48×48px；关键操作建议 56px 高。
- 正文不小于 18px；关键生产数字 28–40px；禁止使用依赖悬停才能发现的关键功能。

### 3.3 状态视觉语言

| 状态 | 颜色与形态 | 动效 |
| --- | --- | --- |
| run | 绿色实心状态点 + “运行”文字 | 走料缓慢流动、辊筒低频旋转 |
| stop | 中性灰状态点 + “停止”文字 | 所有运动停止 |
| warning | 黄色/橙色提示点 + “警告”文字 | 静态提示或低频提示，不改变运行状态 |
| alarm | 红色菱形/状态点 + “报警”文字 | 低频脉冲，不使用高频闪烁；停机级报警按影响范围停止设备 |
| selected | 青蓝描边 + 信息侧栏同步 | 150–200ms 状态过渡 |
| disabled | 低对比灰 + 禁用说明 | 无动效 |

颜色必须与图标、文字共同编码，不能只依赖颜色判断状态。

报警同时存在时，顶部状态栏只显示汇总，不覆盖或隐藏单条报警：显示最高严重级别、活动报警数和待确认数；点击报警区域后打开完整报警列表。

## 4. 界面一：整机浏览产品设计（参数化 2.5D Canvas）

### 4.1 页面目标

以“整线状态总览”为第一任务，以“单元定位与快速操作”为第二任务。操作员无需阅读大量输入框，即可看懂材料从放卷经过十个印刷/干燥单元到收卷的路径。

### 4.2 2.5D Canvas 结构定义

采用固定视角的工业 2.5D Canvas 示意图，强调结构关系、工艺路径和状态，不追求真实三维空间。通过梯形侧面、分层阴影、辊筒椭圆、颜色带和连线形成空间感；所有几何均由设备参数计算生成。

#### 结构层级

```text
PrintingLineCanvas
├── CanvasViewport（页面局部 16:9 视口、逻辑坐标与像素比适配）
├── UnwindUnit（A/B 双轴放卷：活动轴 / 备用轴）
├── InfeedSection（摆臂 / 张力 / 引入）
├── PrintStation × 10
│   ├── StationBody（色组框体与 2.5D 侧面）
│   ├── RollerPair（凹版辊 / 压印辊椭圆）
│   ├── DoctorBlade（刮刀）
│   ├── InkTray（色槽，绑定工艺颜色）
│   ├── Dryer（干燥单元）
│   └── StatusAnchor（状态与报警锚点）
├── OutfeedSection（摆臂 / 张力 / 引出）
├── RewindUnit（A/B 双轴收卷：活动轴 / 备用轴）
├── MaterialWeb（连续走料路径与运动纹理）
└── HitRegions（触控命中区域，不直接依赖视觉像素）
```

#### 参数化维度

| 参数 | 默认值 | 影响范围 |
| --- | ---: | --- |
| `stationCount` | 10 | 色组单元的实例数量与 Canvas 排布 |
| `webWidthMm` | 600 | 材料带宽、顶部材料信息 |
| `lineSpeedMpm` | 24 | 顶部车速、走料与辊筒动画速度 |
| `unwindDiameterMm` | 模拟值 | 放卷圆盘半径、阴影深度与参数显示 |
| `rewindDiameterMm` | 模拟值 | 收卷圆盘半径、阴影深度与参数显示 |
| `activeAxis` | A/B | 当前承载运行卷的轴；另一轴只表达为备用轴，不触发换轴操作 |
| `stationColors[]` | 10 色 | 凹版辊底部彩色半圆弧、色槽和单元详情 |
| `stationRunStates[]` | run/stop | 单元颜色、动效与运行状态图层 |
| `stationAlarms[]` | warning/stop | 报警锚点、等级和影响范围 |
| `tensionN` | 模拟值 | 走料状态与参数卡 |
| `selectedStationId` | 空 | 首次进入不默认选中；点击色组后用于选中描边、右侧详情及跨页面 PU 上下文 |

#### Canvas 视图与交互

- 默认使用固定等距 2.5D 视角，保证放卷、10 个色组与收卷始终完整可见。
- 当前版本固定使用“工艺视图 · 工艺路径”，不提供“结构视图 / 工艺视图”切换，也不提供自由旋转；容器尺寸变化时只自动适配已有设备排布，不改变工艺语义。
- 承印材料带沿统一的压印基准线穿过每个印刷单元的压印辊与凹版辊之间的辊隙，不得绘制在两辊下方或脱离印刷位置。
- 10 个印刷单元在放卷与收卷之间均匀排列，PU10 到收卷之间只保留实际出料走料段，不因布局计算产生无业务含义的大段空白。
- Canvas 绘制与交互分层：背景网格 → 设备阴影 → 设备实体 → 走料带 → 状态标记 → 选中态 → 文字标签。
- 点击设备命中区域选择所在单元，不做复杂零件级选择；命中区域独立于视觉图形并满足 48px 触控要求。
- 选中色组后，Canvas 单元高亮，右侧参数抽屉显示对应信息。
- 每个色组的工艺颜色在凹版辊底部使用彩色半圆弧表示：半圆弧位于凹版辊后侧或下沿，颜色取自 `stationColors[]`；上、下辊筒主体保持金属灰蓝色，不把整只辊筒填成工艺色。
- 彩色半圆弧只表达该色组的印刷工艺颜色，不表达运行、警告、报警或选中状态；运行/停止使用状态点与文字，警告/报警使用独立锚点和标签，选中使用青蓝描边。
- 总览模式下不单独绘制复杂油墨槽和刮刀，彩色半圆弧作为油墨/工艺颜色的简化表达；单击色组进入详情后，主区域默认展示当前 PU 的材料带、压印辊、凹版辊、油墨槽、刮刀和光电眼等结构关系。
- 单击任一色组的完整命中区域（不只限于底部编号文字）后，更新 `selectedStationId`、显示选中态并打开该 PU 的详情；单击不直接跳转页面。
- 右侧详情提供带文字的“查看 PU 检测曲线”按钮。PU2–PU10 点击该按钮后进入锁定标记页，并把当前 `stationId` 作为目标 PU 上下文；进入后直接显示对应曲线、检测窗、偏差和信号状态。
- 不提供双击进入锁定标记：单击 PU 立即显示选中态和右侧详情，进入锁定标记必须点击详情中的“查看 PU 检测曲线”文字按钮。
- PU1 可以单击查看详情和简化原理图，但没有锁定标记曲线入口；入口保持禁用并显示“PU1 暂无锁定标记检测”，不跳转。
- 设备处于停止、警告或报警状态时仍允许进入对应锁定标记页查看；页面继续显示该 PU 的状态和报警，不因跳转清除或确认报警。
- 从锁定标记页点击“返回整机”或通过主导航进入整机浏览时，先处理未应用的检测窗修改，再清除 `selectedStationId`、`sourceStationId` 和报警定位上下文，返回 `/overview`；Canvas 不保留原 PU 高亮，右侧显示整线摘要。在锁定标记页内部切换 PU 不自动返回整机页。
- 报警时保持视图稳定，通过红色锚点、状态标签和报警列表定位，避免自动镜头运动造成误操作。

#### 色组工艺颜色表达

- 彩色半圆弧以显示尺寸为基准，建议弧宽约为凹版辊直径的 `70%–85%`，线宽约 `8–12px`；实际像素随 Canvas 缩放按比例适配。
- 半圆弧与凹版辊主体之间保留约 `2–4px` 的间隔，不能遮挡辊筒轮廓、辊筒中心或状态点。
- 彩色半圆弧统一绘制在凹版辊后侧/下沿，颜色连续、形状一致；不得在相邻色组之间延伸或造成视觉串色。
- 颜色半圆弧不设置独立点击、拖动或调整命中区域，点击该区域时命中所属色组的统一设备区域。
- 颜色、状态和选中三套视觉语义必须独立：工艺色可为紫、洋红、黄等；状态色固定遵循绿色运行、灰色停止、黄色/橙色警告、红色报警；选中态使用青蓝描边。

#### Canvas 绘制约束

- 应用整体仍以 `1920×1080` 为固定设计基准；整机 Canvas 可使用独立逻辑坐标系 `1280×720` 作为参数化绘图基准，但总览模式通过运行时布局计算映射到横向长条容器，不把 `1280×720` 当作固定显示区域，也不通过非等比拉伸破坏设备比例。
- Canvas 以 `fit/scale` 映射到实际 CSS 显示区域，通过 `devicePixelRatio` 放大 backing store 像素，避免高分屏模糊；禁止把逻辑坐标直接当作浏览器屏幕坐标。
- Canvas 实际显示尺寸以运行时容器的 `getBoundingClientRect()` 为准；即使浏览器窗口或容器尺寸变化，也不得假设 Canvas 永远是 `1280×720` 或页面工作区尺寸。
- 所有设备尺寸由 `stationCount`、`webWidthMm`、卷径和安全间距计算；禁止写死 10 个单元的独立像素坐标。
- Canvas 只负责高频视觉层；顶部状态、参数、报警和按钮使用 HTML 语义层，保证可访问性和可读性。
- 设备状态变化只重绘受影响的 Canvas 图层；不因 1s 数据刷新重建整页。
- 预留 `toScreenPoint` / `toWorldPoint` 坐标变换接口，未来可扩展画布缩放或导出。

### 4.3 页面布局

#### 顶部状态栏

- 当前订单号、材料宽度。
- 当前车速（m/min），作为全局最大数字。
- 联动状态：运行、停止、自动加减速、报警。
- 报警灯、最高报警级别、活动报警数和待确认数；报警详情按整机或具体 PU 定位。
- 同时存在多个报警时，顶部优先显示停机级报警；无停机级报警时显示普通预警；报警数量和运行状态分别表达。
- 报警列表按“整机停机级 → PU 停机级 → 整机普通预警 → PU 普通预警/信号异常”排序；同级别内未确认优先，之后按最新发生时间优先。
- 每条报警独立显示来源、标题、说明、发生时间、活动/已恢复状态和确认状态，并提供单条“确认报警”操作；不提供一键确认全部。
- 当前日期时间。

#### 中央主视图（整机总览/详情自适应）

- 默认进入“整机总览模式”：参数化 2.5D Canvas 占据主要工作区，放卷 → 10 个色组 → 收卷完整展开；首次进入不默认选中色组，右侧显示整线状态、实际线速度、需处理报警、最新来源和数据状态。
- 总览模式下，整机 Canvas 使用横向长条内容比例，不强行套用局部 `16:9`；应用整体仍以 `1920×1080` 为固定设计基准。
- 单击色组、点击对应 PU 的报警锚点或点击“查看详情”后进入“整机详情模式”：整线 Canvas 保持可见，右侧展开完整详情面板，并在面板顶部默认展示当前 PU 的简化单元原理图；不自动旋转或飞行定位。
- 新报警出现时不自动进入详情模式，也不改变当前布局；只更新顶部报警汇总、对应色组报警锚点和窄摘要，用户点击报警锚点后才打开详情。
- 点击右上角关闭按钮或“返回整线总览”后，关闭详情、清除当前 `selectedStationId` 和报警定位上下文、取消 Canvas 的 PU 高亮，并将地址恢复为 `/overview`；右侧重新显示整线摘要，整线空间位置不改变。
- 走料路径始终可见。
- 每个色组显示编号、工艺色和状态。
- 放卷、收卷显示当前活动轴 A/B，并明确标注“运行轴”；另一轴以“备用轴”表达。已有卷径、长度和摆臂字段按当前数据可用性展示，不在总览中增加换轴或换卷操作。

#### 右侧上下文面板（窄摘要 / 完整详情两态）

- 默认总览模式显示约 `200–240px`、最小不低于 `180px` 的整线窄摘要；内容包括整线状态、实际线速度、需处理报警、最新来源和数据状态。单击 PU 后直接进入完整详情，不设置“已选中但详情关闭”的中间摘要状态。
- 详情模式右侧显示约 `360–420px` 的完整状态与操作面板，包含当前色组状态、套色偏差、光电眼状态、张力、凹版辊转速、压力、温度、黏度和“查看 PU 检测曲线”入口。
- 详情模式右侧面板默认展示当前 PU 的简化单元原理图；简图只表达承印材料方向、油墨槽、凹版辊、压印辊和光电眼。点击“展开”后在独立详情层查看完整原理图，不挤压整线 Canvas。
- 原理图显示材料带、压印辊、凹版辊、油墨槽、刮刀和光电眼，只用于理解结构与检测关系；点击部件只高亮并显示职责说明，不直接执行设备控制。
- 点击色组主体或报警锚点可展开完整详情；点击右上角关闭按钮或“返回整线总览”恢复整线窄摘要，同时退出当前 PU 上下文。
- 关闭详情只清除界面选择、报警定位上下文和 URL 中的 PU 参数，不改变设备数据、报警生命周期或生产参数。

### 4.4 参数显示分层

#### L1 - 全局常驻

- 车速、整机状态、报警、时间、订单、材料宽度。

#### L2 - 整机页快速浏览

- 放卷/收卷卷径、活动轴（运行轴）、总计长、张力、摆臂位置、速度设定、加减速时间。

#### L3 - 色组详情

- 色组状态、工艺色、凹版辊转速。
- 纵向/横向套色偏差。
- 段间张力、刮刀压力、压印压力、干燥温度、油墨黏度。
- 参数值同时包含单位、正常范围和异常状态，不只显示裸数字。

### 4.5 状态与异常反馈

- `run`：材料带沿走料方向移动，运行单元辊筒同步旋转。
- `stop`：单元变为中性灰，辊筒停转；若整机仍运行，显示“单元停止”而不是隐藏。
- `warning`：不改变整机或 PU 的运行状态；对应单元显示黄色/橙色提示，顶部显示活动报警数量。
- `alarm`：对应单元显示红色锚点、状态标签和报警摘要。停机级报警按影响范围停止对应 PU 或整机；非停机级报警不覆盖真实运行状态。
- 套色偏差先按预警处理：超过预警阈值时显示黄色/橙色提示，不自动改变 `runState`。
- 只有偏差达到停机阈值并持续超过设定时长，才生成停机级报警；默认影响范围为对应 PU，是否扩大到整机由报警配置决定。
- 单次、短时的偏差抖动不得直接触发停机；偏差恢复到正常范围后，预警或停机条件按模拟规则自动恢复。
- 报警产生或恢复后均需要操作员点击“确认报警”；未确认的报警保留醒目标记，并在报警列表中标记“待确认”。
- “确认报警”只记录人工已查看，不代表故障已经恢复，也不自动改变整机或 PU 的 `runState`。
- 报警条件仍存在时，即使已经确认，报警仍保持活动状态并继续显示；只有条件恢复且已确认后，才从活动报警中移除，并保留在报警记录中。
- 停机级报警确认后不得自动重启设备；条件恢复且已确认后才允许单条复位，复位与启动始终是两个独立动作。
- 当前报警状态统一显示为“活动/待确认”“活动/已确认”“已恢复/待确认”“已恢复/待复位”“已复位”；活动报警保持严重级别颜色，但不使用高频闪烁。
- “待复位”只表示停机级报警已经满足 `active = false`、`acknowledged = true`、`resetRequired = true`，即当前可以执行复位；活动故障即使带有复位锁存要求，也不计入“待复位”统计和筛选。
- 活动故障的复位按钮保持禁用并显示“故障仍存在”；故障已恢复但尚未确认时显示“请先确认”；仅在进入“已恢复 / 待复位”状态后显示可操作的“复位报警”。
- 当前报警抽屉只显示活动、待确认和待复位报警；复位后从当前列表移除，但保留 `occurredAt / recoveredAt / acknowledgedAt / resetAt` 等记录字段，暂不增加独立历史页、导出或审计。
- 整机启动需要人工二次确认；整机级停机报警或整机级待复位状态会阻止启动。PU 级停机报警只阻止对应 PU 启动，不自动阻止整机运行。
- PU 启动需要整机运行、对应 PU 无活动停机级报警、对应停机报警已复位且光电眼信号正常；普通警告不阻止启动。启动按钮显示“启动中”反馈，下一次整机状态刷新后进入“运行中”。
- 信号中断属于普通信号警告：保留最后一帧，恢复后连续收到 2 帧有效信号自动恢复，不进入停机级复位流程；中断期间禁止启动对应 PU。
- 多条报警同时存在时不互相覆盖；顶部显示最高严重级别，报警列表按预设优先级排序，每条报警单独确认。
- 偏差表中的纵向/横向数值和报警状态必须与当前 PU、当前检测窗及当前凹版辊微调值保持一致；切换 PU 后不得串用其他色组的偏差。
- 顶部状态将运行状态和报警提示分开表达：整机运行时允许同时显示“运行中”和“有报警”，不把所有报警笼统转换为“停止”。
- PU 单独停止或停机级报警时，整机可以继续运行；只有影响范围为整机的停机级报警才将整机置为停止。
- 光电眼信号中断属于 `signal` 来源的“信号异常”，保留最后一帧曲线并禁止显示为零值或普通停止；单次丢帧不报警，持续达到 `signalTimeoutMs`（默认 2000ms）后才生成报警，是否停机由该异常的影响范围决定。
- 车速改变：动画速度平滑过渡，不直接跳变。
- 整机快速速度预设显示 `24 / 36 / 120 / 150 m/min`；整机页同时展示收放卷计长、活动轴、卷径、摆臂位置、自动加速时间和自动减速时间。
- 状态刷新：数值每 1s 更新，布局不得因位数变化抖动。

## 5. 界面二：锁定标记产品设计

### 5.1 页面目标

将原页面中分散的色组、曲线、窗口位置、凹版辊微调和偏差表重组成一条清晰工作流：

`选择 PU 色组 → 观察并冻结波形 → 绘制检测窗 → 编辑检测窗 → 查看/微调偏差`

### 5.2 页面布局

#### 顶部色组条

- PU2–PU10 横向排列，每个色组按钮显示：编号、工艺色、光电眼状态、是否已有检测窗。
- 当前色组用高对比选中态，报警或信号异常独立标记。

#### 中央曲线画布（页面核心，约 70% 高度）

- 曲线 Canvas 属于页面局部区域，不等同于整屏 `1920×1080`；其逻辑坐标与实际 DOM 尺寸解耦。
- X 轴：采样序号 0–1199。
- Y 轴：光电眼信号幅值，建议产品量程 0–100%。
- Y 轴显示单位统一为“信号强度（%）”，固定范围 0–100%，建议刻度为 0、25、50、75、100；后续若确认真实工业单位，只替换显示映射，不改变检测窗坐标和换算规则。
- 每 500ms 接收完整 1200 点并重绘。
- 叠加 2–3 个脉冲峰、检测窗、首色/前色/本色参考线与底部印刷颜色条带。
- 参考线与颜色条带均使用直接标签，减少来回查看图例。
- 曲线视觉层级固定为：低饱和暗红/棕红细线表示实时波形；青蓝半透明高亮表示当前选中的检测窗；绿色/红色/黑色细竖线分别表示首色/前色/本色参考标记；底部连续颜色条只作印刷颜色分布辅助。
- 检测窗选中或编辑时始终位于叠加层最上方；参考线可以穿过检测窗显示，不因重叠而隐藏；底部颜色条不参与选择或拖动。

#### 右侧检查面板

- 当前 PU 色组与信号状态。
- 检测窗数据坐标：`xMin / xMax / yMin / yMax`。
- 色标偏差表：本色、前色、首色 × 纵向、横向。
- 每个偏差值同时显示数值、单位、正负方向、对应参考对象、预警/停机阈值和当前状态；不能只显示无单位的裸数字。
- 首色、前色、本色的参考位置由配置或后台数据提供；当前演示版先使用 `MockReferenceConfig` 模拟配置首色位置，真实设备接入后再由配方、示教或后台数据替换。如果某一参考位置缺失，显示“暂无参考位置”，对应纵向偏差显示 `—`，不显示为 0。
- “首色印刷色组”和“首色参考基准”是两个不同概念：前者表示订单/工艺中的实际色组，后者表示套色计算使用的基准位置。重新设置首色参考基准不会改变 PU 的实体色组或工艺颜色。
- 首色参考基准是当前套色计算的主参考线；当前色相对首色计算主纵向偏差，前色作为相邻色辅助参考。当前演示版不提供首色参考线拖动或示教修改，首色位置只从模拟配置读取。
- 纵向偏差的正方向定义为“实际检测位置沿曲线 X 轴增加方向、即画面向右偏离参考位置”；负方向为向左。横向偏差的正方向定义为“凹版辊/横向位置向右偏离目标位置”；方向在表头或图例中持续显示。
- 当前选中对象和可执行操作。

#### 底部工具条

- 不设置“编辑/查看”模式切换；按触摸位置自动判断操作对象，减少现场人员的模式理解和切换成本。
- 当前 PU 没有已保存检测窗且已有曲线数据时，系统自动显示一个默认草稿框；不要求用户先点击按钮。当前 PU 已有检测窗时，工具栏显示“重新创建检测窗”，仅用于发起替换流程。
- 没有处于创建草稿流程时，空白曲线区域的拖动只用于平移曲线；创建替换草稿时由界面明确标记当前草稿范围。
- 删除检测窗。
- 窗口位置微调：左/右步进；用于在拖动检测窗完成粗定位后进行横向精调。
- 凹版辊微调：左/右步进，显示当前值和 mm 单位；与检测窗位置微调分开操作。
- 参考位置操作：当前版本不提供拖动参考线；如需改变目标位置，必须先进入“停止/低速示教”状态，再使用“示教/重新锁定”操作，并明确显示“参考位置已更新”。
- 示教/重新锁定流程：设备处于停止或配置的低速示教状态后，先在右侧选择首色、前色或本色，再点击“重新锁定参考位置”；系统仅在当前检测窗内寻找该标记的有效波峰/波谷。
- 找到候选位置后显示预览参考线并标记“待确认”，不立即改变原参考线、偏差或报警状态；点击“确认锁定”后才提交新参考位置，并显示“参考位置已更新”。
- 点击“取消锁定”或切换 PU 时，丢弃候选位置，原参考线和偏差保持不变；一次只更新当前选中的一个标记，不影响其他两个标记。
- 当前没有检测窗、窗口内没有有效波峰/波谷、信号中断或处于信号恢复中时，不能完成锁定，显示具体原因，原参考线保持不变。
- 首色参考基准在正常运行和检测窗编辑过程中不可直接拖动；进入示教/重新锁定流程后可以重新设置。确认新的首色参考基准后，相关色组的纵向套色偏差按新基准重新计算。
- 正常运行或自动套色状态下点击“重新锁定参考位置”时，按钮不可提交并提示“请先进入停止/低速示教状态”；不因点击该按钮自动停机或自动降速。
- 进入示教状态后，界面显示当前设备状态和允许的示教速度；如果设备从示教状态恢复运行，未确认的候选参考位置自动取消，原参考线保持不变。
- 曲线查看按钮：放大、缩小、左移、右移、恢复视图。按钮是工业触摸屏上的主要操作入口，按钮不可用时显示禁用态，不产生越界操作。
- 冻结/恢复实时曲线。

#### 曲线叠加层与触控命中

- 对象显示优先级为：正在编辑的检测窗 → 当前选中的检测窗 → 首色/前色/本色参考标记 → 实时波形 → 底部颜色条。
- 已保存检测窗使用灰色背景和灰色实线，表示当前有效区域；草稿检测窗使用青蓝色半透明背景和青蓝色虚线，并标记“待确认”；正在编辑时使用青蓝色高亮描边和手柄。检测窗保持 8 个手柄，未选中时降为细边框，避免遮挡波形。
- 首色/前色/本色使用细竖线、顶部色块和直接文字标签，不显示调整手柄；参考线视觉颜色固定为绿色、红色、黑/深灰色。
- 实际命中区域独立于视觉线宽：参考线不小于 20px，检测窗手柄不小于 40×40px，检测窗主体命中高度不小于 40px；底部颜色条不参与交互。
- 首色、前色、本色参考线在当前调整过程中表示目标位置，不支持直接拖动、缩放或手动调整；参考线不设置调整手柄，命中参考线时不进入编辑状态。参考位置可通过示教、重新锁定、配方切换或后台数据更新。

#### 曲线视口与检测窗关系

- 默认视口为完整数据范围：X=`0–1199`，Y=`0–100%`。本版本只对 X 轴进行平移和缩放，Y 轴量程保持 `0–100%`，避免改变信号强度的直观含义。
- 点击“放大/缩小”以当前视口中心为基准调整 X 范围；点击“左移/右移”按当前视口宽度的 10% 移动 X 范围，到 `0` 或 `1199` 边界自动限制。视口宽度达到最小配置值时禁用继续放大，回到完整范围时禁用继续缩小。
- 直接操作按命中对象区分：拖动检测窗主体移动窗口，拖动 8 个手柄调整大小，在空白曲线区域水平拖动平移曲线；缩放优先使用工具栏按钮，避免触摸手势与窗口手柄冲突。
- 命中优先级为“手柄 → 检测窗主体 → 新建流程 → 空白区域平移”；检测窗主体和手柄的命中区域优先于曲线平移，避免拖动窗口时误移动视口。
- 视口平移或缩放时显示当前 X 范围和“恢复视图”按钮；恢复视图后回到完整 `0–1199` 范围，并保留检测窗和偏差数据不变。
- 曲线平移、缩放和“恢复视图”属于查看操作，只改变当前曲线视口，不修改检测窗的 `xMin / xMax / yMin / yMax`、偏差值或其他业务数据。
- 检测窗始终以数据坐标重新投影到当前视口；曲线平移或缩放后，检测窗跟随对应数据位置一起移动和缩放，而不是固定在原屏幕像素位置。
- 平移后检测窗全部或部分位于当前可视范围外时，不删除或裁剪其业务数据；“恢复视图”后应在完整数据范围内重新显示。
- 只有拖动检测窗本体、拖动 8 个调整手柄或点击窗口位置左右微调按钮，才会修改检测窗数据；曲线拖动/缩放不触发偏差重新计算。
- 拖动检测窗本体用于快速粗调位置，窗口位置左右按钮用于按采样点进行横向精调；两者修改的是同一个检测窗的 `xMin / xMax`，不构成两套位置状态。
- 窗口位置微调保持检测窗宽度及 `yMin / yMax` 不变；单击左/右按钮移动 1 个采样点，按住后连续移动，超过 500ms 后加速为每次 5 个采样点；松开立即停止，到达数据边界自动限制。
- 检测窗拖动或窗口位置微调属于软件检测参数调整，修改 `xMin / xMax`，主要影响纵向偏差；凹版辊微调属于设备位置参数调整，修改独立的凹版辊横向偏移值，主要影响横向偏差。
- 两类操作独立保存、独立显示、单位不同且互不替代：检测窗位置使用采样点坐标，凹版辊微调使用 `mm`；调整其中一类时，另一类控件的值保持不变。
- 凹版辊微调单击左/右按钮移动 `0.01mm`；长按先按 `0.01mm/次` 连续移动，按住超过 `500ms` 后加速为 `0.10mm/次`；松开、切换 PU 或到达边界时立即停止。
- 凹版辊微调默认允许范围为 `-5.00mm～+5.00mm`，实际范围由当前 PU 的配置提供；到达边界自动限制或禁用，不允许越界。
- 凹版辊微调每次操作结束后立即提交并更新横向偏差；检测窗 `xMin / xMax / yMin / yMax`、纵向偏差和检测窗宽度不受影响。
- 当前没有有效波峰/波谷或信号中断时，仍允许调整凹版辊微调；横向偏差显示 `—`，不弹窗阻止操作。信号恢复并完成有效帧稳定后重新计算横向偏差。
- 检测窗是完整二维有效区域：`xMin / xMax` 限定采样位置，`yMin / yMax` 限定信号幅值；只有同时落在 X、Y 范围内的波峰或波谷才参与当前窗口的有效信号判断。
- 检测窗移动或调整大小时，当前参考位置保持不变，系统按新的检测结果重新计算纵向偏差；执行示教、重新锁定、配方切换或后台更新后，参考线可更新并重新计算偏差。曲线平移、缩放或恢复视图时，参考线按数据坐标重新投影。

### 5.3 触控画框交互

#### P0 基础路径（本次必做）

- 页面默认即可直接画框：用户在曲线有效绘图区按下指针，拖动形成矩形，松开后立即保存检测窗。
- 保存前将起点和终点统一整理为 `xMin ≤ xMax`、`yMin ≤ yMax`，并将屏幕坐标换算为数据坐标；检测窗随后的重绘必须与原位置一致。
- 本次基础路径不要求“新建检测窗”“确认保存”“撤销”或替换确认按钮，保证基础画框演示可以一次完成闭环。
- 当前 PU 按单窗口处理；若用户再次画出有效矩形，最新结果覆盖当前窗口即可。替换保护等更复杂规则属于下方增强路径，不作为 P0 前置条件。
- 若用户只是点击一下，或拖出的矩形宽度小于 12 个采样点、垂直高度小于 5% 量程，松手后丢弃本次结果并提示“请拖出更大的检测区域”；如果已有检测窗，原窗口保持不变。
- 指针拖出绘图区边界时，将终点限制在绘图区边缘后再计算数据坐标；因此不会保存越界的检测窗。

#### 增强路径（P1，按剩余时间实现）

以下规则用于补充本次交付的业务闭环和加分能力，不阻塞 P0 基础画框；优先实现信号、报警和检测窗事务的最小闭环：

1. 默认处于直接操作状态；当前 PU 没有已保存检测窗且已有曲线数据时，页面自动生成一个居中默认草稿框。
2. 默认草稿框显示“草稿/待确认”标记，用户可以直接拖动主体或 8 个手柄调整，不需要先点击“新建检测窗”。
3. 用户点击“确认保存”后，草稿矩形转换并保存为数据坐标，成为当前 PU 的唯一检测窗；确认前不参与有效信号判断、偏差计算或报警。
4. 当前 PU 已有检测窗时，点击“重新创建检测窗”先提示替换影响；确认后生成新的默认草稿框，旧检测窗在草稿确认前继续保留。
5. 用户在创建替换草稿时可点击“取消”，或切换 PU；取消本次草稿，不改变原有检测窗；已完成提交的检测窗保留。
6. 直接拖动已保存检测窗主体移动窗口，拖动手柄调整大小；已保存检测窗在拖动或调整大小松手后立即生效，不需要再次点击确认。不在草稿流程时，在空白曲线区域拖动平移曲线。
7. 切换 PU 色组时，各色组分别保留自己的检测窗；切换回该 PU 后恢复其窗口和选中状态。
8. PU2–PU10 分别维护各自的最新曲线、检测窗、偏差、凹版辊微调和信号状态；切换 PU 只切换当前查看上下文，不重置其他 PU 数据。
9. 页面只绘制当前选中 PU 的曲线；首次进入锁定标记页默认选中 PU2，信号源可以在后台分别更新各 PU 的最新帧；切回某个 PU 时显示其最近一帧和对应编辑状态。
10. 如果某个 PU 尚未收到过曲线，显示“当前 PU 暂无信号数据”；如果已经收到过数据但暂时没有新帧，保留最后一帧并显示“信号中断”。单次丢帧不立即生成报警，持续中断达到配置的 `signalTimeoutMs`（默认 2000ms）后才进入信号异常处理。
11. 切换 PU 时未完成的草稿流程直接取消，已提交的检测窗、微调和冻结状态保留；切换 PU 不清除或确认其他 PU 的报警。

#### 默认检测窗草稿

- 当前 PU 有可用曲线数据且没有已保存检测窗时，页面自动生成一个居中草稿框：默认宽度约 120 个采样点，默认高度约为当前 0–100% 量程的 30%。
- 草稿框只用于提供可调整的起始位置，显示“待确认”或“草稿”标记；用户可以拖动主体或 8 个手柄调整，点击“确认保存”后才成为当前 PU 的唯一检测窗。
- 草稿框未确认保存前不参与有效波峰/波谷判断、偏差计算或报警；点击“取消”则直接丢弃草稿，不影响原有检测窗。
- 当前 PU 没有任何曲线数据时不生成草稿框，只显示“当前 PU 暂无信号数据”；已有最后一帧但信号中断时允许基于该帧创建或调整草稿，同时持续显示“信号中断”。

#### 已保存检测窗编辑规则

- 已保存检测窗拖动主体或 8 个手柄时，拖动过程显示实时预览；指针松手后立即提交新的数据坐标，并立即重新计算有效信号和偏差。
- 已保存检测窗的左右位置微调按钮同样在每次单击或长按结束后立即生效，不需要额外确认。
- 微调按钮长按时以 1 个采样点/次开始连续移动，按住超过 500ms 后以 5 个采样点/次加速；松开、切换 PU 或到达边界时立即停止。
- 编辑开始时保留上一次有效位置作为本次编辑快照；编辑过程中点击“取消本次调整”或按 `Esc`，恢复到该快照，不产生新的检测窗数据。
- 如果调整结果小于最小尺寸或超出有效范围，松手时不提交，恢复到编辑前的有效位置并给出简短提示。
- 已保存检测窗的编辑不提供 5 秒撤销；需要回退时使用编辑过程中的“取消本次调整”，或再次拖动/微调到目标位置。

#### 单窗口规则

- 检测窗是每个 PU 的唯一检测窗，不支持同一 PU 同时存在多个窗口、窗口层叠或多选。
- 当前 PU 已有检测窗时，点击“重新创建检测窗”提示“重新创建将替换当前窗口”；确认后生成默认草稿，旧检测窗在草稿确认保存前继续保留，点击取消则保留旧窗口。
- 删除检测窗采用“确认后立即删除”：点击删除后显示“确定删除当前 PU 的检测窗？”，用户确认后立即删除，取消则保留原窗口。
- 右侧数据面板始终显示当前 PU 唯一检测窗的数据；有曲线但无窗口时显示默认草稿及“确认保存/取消”，无曲线时显示“当前 PU 暂无信号数据”。创建中的默认框属于草稿，不计入已保存检测窗。

#### 坐标换算规则

设曲线 Canvas 的实际内容区域（不含坐标轴、标签和颜色条带）在 DOM 中的矩形为 `plotRect = { left, top, width, height }`，当前 X/Y 数据域分别为 `[xMin, xMax]`、`[yMin, yMax]`。`pointerX/Y` 必须先通过 `clientX/Y - plotRect.left/top` 转换为绘图区内的 CSS 像素坐标，再进行数据换算：

```text
localX = clamp(pointerClientX - plotRect.left, 0, plotRect.width)
localY = clamp(pointerClientY - plotRect.top, 0, plotRect.height)
dataX = xMin + localX / plotRect.width  × (xMax - xMin)
dataY = yMax - localY / plotRect.height × (yMax - yMin)
```

- Canvas 内部逻辑坐标（例如 `1280×720`）到实际 CSS 像素通过同一个 `fit/scale` 变换；Pointer Events 的 `clientX/Y` 不直接与逻辑坐标相减。
- 创建、拖动、缩放窗口时统一经过同一个坐标转换模块，并统一使用当前帧的 `plotRect`。
- 保存数据坐标而不是像素坐标，因此曲线缩放或画布尺寸改变后窗口仍与数据对齐。
- 数据结果限制在当前量程内；最小检测窗建议为 12 个采样点 × 5% 幅值。
- 检测窗的 X、Y 数据范围均参与检测结果计算；拖动窗口本体改变位置，拖动边或角改变对应的 X/Y 范围，不能把 Y 范围仅作为装饰性显示。
- 触控手柄视觉尺寸可为 12–16px，但实际命中区域不小于 40×40px。
- 检测窗只能创建和编辑在曲线有效绘图区内；指针拖到边界外时，窗口边界自动吸附并限制在绘图区边缘。
- 画框支持从左向右或从右向左完成，松开后统一整理为 `xMin ≤ xMax`、`yMin ≤ yMax` 的数据范围。
- 若新建或调整后的窗口小于最小尺寸，松开时不提交本次结果：新建时取消创建，编辑时恢复到上一次有效位置，并给出简短提示。
- 信号中断时允许基于保留的最后一帧继续调整检测窗，但必须持续显示“信号中断”状态和最后有效帧时间，不能让用户误以为数据仍在实时更新。
- 信号中断期间不使用旧帧冒充新的实时检测结果：偏差显示 `—` 并提示“等待信号恢复”，检测窗仍保留且可编辑。
- 信号恢复后，第一帧有效数据只用于恢复曲线和更新“信号恢复中”状态；连续收到 2 帧有效数据后，才恢复偏差计算和有效信号判断，避免恢复瞬间的单帧抖动触发误报警。

### 5.4 实时刷新与编辑冲突处理

- 默认实时刷新，500ms 替换整帧波形。
- 提供显式“冻结/恢复实时”按钮。点击“冻结”后进入手动冻结状态，曲线画面停留在当前最后一帧；按钮文字变为“恢复实时”，并显示“已冻结”和最后一帧时间。
- 手动冻结只冻结曲线的显示，不暂停后台数据接收、偏差计算或报警判断；后台仍按 500ms 接收并缓存最新帧，报警仍按实时数据更新。
- 点击“恢复实时”后立即显示当前 PU 缓存的最新一帧，并恢复 500ms 实时刷新；如果期间没有新帧，继续显示原冻结帧并保留数据状态提示。
- 用户开始画框、拖动或缩放检测窗时，若当前未处于手动冻结状态，波形视觉自动进入“编辑临时冻结”；编辑结束后延迟 300ms 自动恢复实时。若用户原本已手动冻结，编辑结束后仍保持手动冻结，不自动恢复。
- 编辑临时冻结只影响曲线视觉刷新，参考线、检测窗和数据面板保持可编辑；取消画框或完成编辑后按上述规则恢复/保持状态。
- 切换 PU 时，各 PU 独立保存手动冻结状态、冻结画面和最新帧时间；切换回该 PU 后恢复其对应显示状态。手动冻结不影响其他 PU 的后台接收和报警。
- 刷新曲线只更新曲线路径，不重建整个页面或检测窗节点。
- 显示“最后显示帧时间”和“最新接收帧时间”；两者不一致时提示“已冻结，后台仍在接收”。数据中断时保留最后一帧并显示“信号中断”。

## 6. 数据产品模型

### 6.1 数据源边界

```text
MockMachineSource（每 1s）
  → machine store
  → 顶部状态栏 / 2.5D Canvas 设备 / 参数与报警

MockSignalSource（每 500ms）
  → signal frame buffer
  → 曲线渲染层 / 信号异常报警

用户交互
  → mark window store
  → 检测窗叠加层 / 偏差表 / 色组状态

P1 可选数据源
  → trend buffer / event log
  → 趋势图 / 最新事件列表
```

数据源职责与推送约束：

- `MockSignalSource` 只负责生成光电眼信号帧和信号质量状态；每 500ms 推送一帧完整数据，单帧必须包含恰好 1200 个 `{ x, y }` 点，并提供时间戳、参考线和颜色条数据。
- `MockMachineSource` 只负责生成整机快照；每 1s 更新车速、整机运行状态、PU2–PU10 状态和报警集合。
- 数据源只向 Store 发布数据或事件，不直接调用组件、修改 Canvas 或操作 DOM；定时器、固定随机种子和演示场景脚本由数据源模块自身管理。
- `machine store`、`signal frame buffer` 和 `mark window store` 分开维护：整机刷新不得清空曲线或检测窗，曲线刷新也不得重置报警、PU 状态或用户编辑中的检测窗。
- `signal frame buffer` 按 `stationId` 分桶保存 PU2–PU10 的最新帧；页面只绘制当前选中的一桶数据，切换 PU 时恢复对应曲线和编辑上下文。
- `signal frame buffer` 同时保存每个 PU 的 `latestReceivedFrame`、`displayedFrame`、`latestReceivedAt`、`displayedAt` 和 `freezeMode`（`live` / `manual` / `edit`）；手动冻结时只锁定 `displayedFrame`，不停止接收 `latestReceivedFrame`。
- 检测窗、偏差、凹版辊微调和冻结状态均按 `stationId` 隔离保存；切换 PU 不清除任何其他 PU 的报警或待确认状态。切回 PU 后恢复该 PU 的显示帧和冻结状态。
- 页面组件只从 Store 读取数据并派生视图状态；用户操作通过 Store action 更新检测窗、冻结状态、报警确认和微调值，不能绕过 Store 直接修改源数据。
- 页面离开或数据源停止时，必须清理对应定时器和订阅；重新进入页面不得产生重复推送或重复报警。

### 6.2 整机数据建议（P0 最小模型）

```ts
  | 'PU1' | 'PU2' | 'PU3' | 'PU4' | 'PU5'
  | 'PU6' | 'PU7' | 'PU8' | 'PU9' | 'PU10'

interface ReelAxisSnapshot {

}

  id: string
  sourceType: AlarmSourceType
  sourceId: string
  severity: AlarmSeverity
  scope: AlarmScope
  title: string
  message: string
  active: boolean
  acknowledged: boolean
```

P0 不要求完成收放卷参数卡、趋势图、事件列表或全部工艺参数的完整界面展示。收放卷的活动轴、A/B 轴计长、卷径、卷径报警阈值、摆臂位置和张力先纳入最小数据模型，便于 Canvas 和模拟数据保持结构完整；对应的详细参数展示仍属于 P1。

#### P1 扩展模型

```ts
type MetricStatus = 'normal' | 'high' | 'low' | 'alarm'

interface ProcessMetric {
  value: number

  normalRange?: { min: number; max: number }
  status: MetricStatus

interface PrintStationP1Metrics {
  doctorBladePressure?: ProcessMetric
  impressionPressure?: ProcessMetric
}

interface TrendPoint {
  timestamp: number
  speedMpm?: number
  tensionN?: number
```

P1 字段按功能启用：`PrintStationP1Metrics` 用于刮刀压力、压印压力及带单位/正常范围/越限状态的参数卡；`TrendPoint[]` 用于最近 60 秒车速或张力趋势；`MachineEvent[]` 用于最新事件列表。P1 字段不作为 P0 提交门槛。

#### 状态聚合规则

- `runState` 只表达运行或停止；`motionPhase` 表达空闲、稳定运行、自动加速或自动减速；报警不与运行状态互斥。
- `warning` 只提示，不改变 `runState`；界面显示黄色/橙色警告。
- `stop` 级报警显示红色报警。`scope: 'station'` 只停止对应 PU；`scope: 'machine'` 才停止整机。
- 顶部整机状态按 `runState` 显示“运行/停止”，报警灯和活动报警数量独立显示；因此允许“运行中 + 有报警”。
- PU 显示状态按自身 `runState` 和活动报警分别编码；PU 停止不自动推导为整机停止。
- 活动报警数量通过 `MachineSnapshot.alarms` 与各 `PrintStation.alarms` 聚合计算，不重复存储；`MachineSnapshot.alarms` 只存整机级报警，各 PU 报警只存于对应 `PrintStation.alarms`。
- 信号中断作为 `sourceType: 'signal'` 的报警存于对应 PU 的 `alarms`，不当作普通停止或零值。
- 报警产生时 `active = true`、`acknowledged = false`；界面显示“待确认”并提供明确的“确认报警”按钮。
- 操作员确认后将 `acknowledged` 置为 `true` 并记录 `acknowledgedAt`；若报警条件仍存在，`active` 继续保持 `true`，不自动恢复运行。
- 报警条件恢复后将 `active` 置为 `false` 并记录 `recoveredAt`；若尚未人工确认，仍保留为“已恢复，待确认”，直到确认后才从活动/待处理列表移除并写入报警记录。
- 顶部“活动报警数”只统计 `active = true` 的报警；“待确认数”单独统计所有 `acknowledged = false` 的报警，避免已恢复但未确认的报警被忽略。
- 最高报警级别和报警列表均由聚合后的报警集合派生，不在 `MachineSnapshot` 中重复存储；排序规则为 scope/等级优先、未确认优先、最新发生时间优先。

### 6.3 曲线与检测窗数据建议

```ts
interface SignalFrame {
  stationId: Exclude<StationId, 'PU1'>
  timestamp: number
  points: Array<{ x: number; y: number }> // 恰好 1200 点
  references: {
    first: number
    previous: number
    current: number
  }
  colorBand: Array<{ from: number; to: number; color: string }>
}

// 当前演示版：references.first 从 MockReferenceConfig 读取，作为首色主参考线；
// previous/current 用于展示相邻色和当前色位置，真实设备接入后再替换参考位置来源。

// 信号连续无新帧超过 signalTimeoutMs 才进入“信号异常”；默认 2000ms。
// 单次丢帧只显示“信号中断”状态，不立即生成报警；恢复需连续 2 帧有效数据。

interface DetectionWindow {
  id: string
  stationId: Exclude<StationId, 'PU1'>
  xMin: number
  xMax: number
  yMin: number
  yMax: number
}

// 业务约束：每个 stationId 最多一条 DetectionWindow。
// selectedWindowId 作为界面临时状态单独存储，不写入检测窗业务数据。
```

#### 偏差计算口径

- 首色位置作为当前演示版的主参考线，先由 `MockReferenceConfig` 提供；真实设备接入后再由配方、示教或后台数据提供。
- 当前 PU 的主纵向偏差比较当前检测到的色标位置与首色参考线位置：`主纵向偏差 = 当前实际检测位置 - 首色参考位置`。
- 前色参考线用于相邻色辅助比较：`相邻纵向偏差 = 当前实际检测位置 - 前色参考位置`；本色位置用于显示当前 PU 实际检测位置和对应上下文，不使用固定偏移量伪造偏差。
- 实际检测位置优先取当前检测窗内的目标峰位置；演示数据中可使用峰位置与检测窗位置推导稳定的模拟结果，不能完全随机跳变。
- 纵向偏差正值表示实际位置沿曲线 X 轴增加方向、即画面向右偏离参考位置；负值表示向左偏离。原始计算单位为采样点，若需要显示毫米，通过可配置的 `samplePitchMm` 转换，不把换算常数写死在视图中。
- 横向偏差比较当前凹版辊/横向位置与目标位置：`横向偏差 = 当前横向位置 - 目标横向位置`；正值表示向右偏离，负值表示向左偏离，显示单位为 `mm`。
- 移动检测窗会改变当前窗口内的有效检测位置，从而联动纵向偏差；调整凹版辊微调值联动横向偏差；曲线拖动或缩放只改变查看范围，不改变偏差业务值。
- 检测窗上下边界或角点改变 `yMin / yMax` 后，系统重新筛选窗口内有效波峰/波谷；若目标信号落在 Y 范围外，则当前窗口不产生有效检测结果，并显示对应提示。
- 检测窗处于“寻找信号”或“未检测到有效信号”时仍然保留用户编辑结果；系统不弹窗、不自动删除窗口、不把偏差填为 0，也不因单次未匹配直接触发报警。
- 只有当前窗口找到符合条件的有效波峰/波谷后才计算并显示偏差；信号持续中断则进入“信号中断”处理，保留最后一帧并按报警规则处理。
- 信号中断超过 `signalTimeoutMs` 时，当前 PU 的偏差显示 `—` 并提示“等待信号恢复”；恢复第一帧有效数据后进入“信号恢复中”，连续收到 2 帧有效数据后才重新计算偏差。信号异常报警进入“已恢复，待确认”，不自动隐藏。
- 检测窗调整只更新 `DetectionWindow.xMin/xMax`，凹版辊微调只更新当前 PU 的 `plateLateralOffsetMm`；两者不得共用一个字段或互相覆盖。
- 真实设备接入后，只替换“实际检测位置、参考位置和单位换算”的计算模块，不改变检测窗数据结构、正负方向和页面交互口径。

### 6.4 模拟规则

- 整机每 1s 生成一个快照，速度在目标速度附近平滑变化，不使用完全随机跳数。
- 正常演示时 10 个色组大部分为 `run`；按可控脚本分别触发一次 PU 单独停止、一次普通 `warning` 和一次整机范围的停机级 `stop` 报警，保证现场演示可复现并展示状态分离。
- 演示脚本至少覆盖“整机运行 + PU 警告”和“整机运行 + PU 停机级报警”两个场景；前者保持整机运行，后者按 `scope` 决定仅停 PU 或停整机。
- 曲线使用基础噪声 + 缓慢漂移 + 2–3 个高斯/尖峰脉冲；每帧峰值轻微移动。
- 偏差值由参考线与检测窗/峰位置推导或稳定模拟，避免与曲线完全无关。
- 纵向主偏差按“当前实际检测位置 - 首色模拟参考位置”计算，窗口移动后按当前窗口内的有效峰位置联动变化；前色只作为相邻色辅助比较；横向偏差按“当前凹版辊位置 - 目标位置”计算，凹版辊微调后联动变化。
- 偏差原始 X 坐标使用采样点，显示毫米时通过可配置的 `samplePitchMm` 换算；未获得真实标定值前，演示场景使用固定配置值。
- 检测窗内没有有效波峰/波谷时，偏差字段显示 `—`，不伪造零值；窗口重新覆盖有效信号后，偏差值自动恢复计算。
- 手动冻结期间曲线显示保持最后一帧，但后台仍持续接收新帧并更新信号质量、偏差和报警；点击“恢复实时”后立即显示最新缓存帧。
- 编辑临时冻结只在画框、拖动或缩放期间生效；编辑结束 300ms 后恢复实时，若编辑前已手动冻结则继续保持手动冻结。
- 偏差处于预警阈值与停机阈值之间时生成 `warning`，只更新偏差提示，不改变 PU 或整机运行状态。
- 偏差达到停机阈值后启动持续计时；只有连续超过 `stopPersistMs` 才生成 `stop` 报警，并按 `stopScope` 停止对应 PU 或整机。
- 演示脚本至少覆盖一次短时偏差预警和一次持续严重偏差，确保可以展示“先预警、后停机”的差异；阈值和持续时长从 `registerDeviationLimits` 读取，不写死在视图中。
- 模拟信号源应覆盖一次短时丢帧（不报警）和一次超过 `signalTimeoutMs` 的持续中断（生成信号异常并在恢复后保留待确认状态）。
- 模拟信号源恢复时应先产生 1 帧“信号恢复中”，再在第 2 帧有效数据后恢复偏差计算，保证该状态可复现和验收。
- 使用固定随机种子和相对页面加载时刻计算的自动时间线，使面试演示结果可预测；每次刷新从相同初始状态开始，关键运行/报警阶段每 90 秒才切换一次。

## 7. 工业触控与安全约束

- 关键操作不使用纯图标，必须有可见文字。
- 手动升/降速采用“按住执行，松开停止”；若实现为点击，则必须有确认或明确执行反馈。
- 清零、删除检测窗等破坏性操作需二次确认；重新创建替换旧窗口需在生成草稿前提示覆盖影响，草稿确认保存前可取消并保留旧窗口。
- 参数设定同时展示当前值、目标值、单位和允许范围。
- 禁止高频闪烁；报警动效频率低于 2Hz，并提供文字说明。
- 所有数值使用等宽数字，单位位置固定，避免刷新引起布局抖动。
- 以工业触摸屏为主要操作方式，鼠标提供等价的辅助操作，Pointer Events 作为统一交互模型。
- 关键业务流程不依赖鼠标悬停；触摸和鼠标均可完成 PU 切换、画框、窗口拖动/缩放、微调、冻结/恢复等操作。
- 键盘仅作为辅助方式，支持焦点导航、Enter 确认、Delete 删除选中检测窗、Esc 取消当前画框或退出编辑，便于可访问性和现场调试。

- 参数化设备结构如何由数组生成 10 个色组。

## 11. 关键产品取舍

1. **2.5D Canvas 是第一阶段的表达方案。** 用固定视角、分层绘制和参数化几何强化整线结构、走料和单元定位；不引入完整 3D 的视角遮挡、模型资源和运行成本。
2. **两个界面权重相同。** 整机页体现 Canvas 业务建模和状态联动；锁定标记页体现图形绘制、坐标换算与性能，是必做核心，不能因视觉表现投入而缩水。
3. **减少常驻输入，保留上下文操作。** 把原页大量数字框重组成预设、步进、滑块和选中单元详情，降低认知负荷。
4. **检测窗保存数据坐标。** 这是保证缩放、平移与尺寸变化后仍准确的基础设计决策。
5. **演示数据必须可复现。** 使用场景脚本而非纯随机，保证可选录屏或面试现场都能稳定出现状态变化、脉冲峰和报警。

## 12. 已确认的模拟参数

- `signalTimeoutMs = 2000ms`：连续 2000ms 没有收到新曲线帧后，当前 PU 进入“信号异常”。
- 信号中断期间保留最后一帧曲线，偏差显示 `—`，不以空白或零值伪装成正常数据。
- 信号恢复后先进入“信号恢复中”；连续收到 2 帧有效数据后，恢复偏差计算和有效信号判断。
- 信号异常默认影响当前 PU，不直接让整机停机；是否扩大影响范围由报警配置决定。
- 信号异常报警需要人工确认；确认只表示操作员已查看，不代表故障已经恢复，也不自动重启设备。
- 以上参数属于本版本的前端模拟规则，未来接入真实设备时可以由产品/工艺配置调整，但不改变本版本的界面状态语义。
